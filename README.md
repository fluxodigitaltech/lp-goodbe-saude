# lp-goodbe-saude

Landing page da unidade **GoodBe Saúde** (Mirandópolis, São Paulo/SP).
HTML único portátil (fotos e logos embutidos em base64), servido por nginx:alpine.
Mesmo design/template aprovado da Altino Arantes.

- Deploy: Easypanel Server 1, projeto `site`, serviço `lp-goodbe-saude` (build por Dockerfile, autoDeploy).
- WhatsApp: (11) 2577-2860 (variável `WHATSAPP` no fim do index.html).
- Fotos: frames do vídeo tour da unidade (o ZIP do Drive da Saúde só tinha o vídeo, sem fotos).
